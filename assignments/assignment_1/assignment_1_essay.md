Based on the lesson, reproducibility requires the safeguarding of raw data, seperation between data and code that preserves all transformations, and documentation. The file structure for 
assignment 1 ensures data is separated from the scripts that may transform them in their respective folders while any documentation like r versions is preserved in the docs folder or readme. Segmenting all 
these factors reduces risk when reprodicing results like writing new files into folders that have files which need to be iterated over when running analysis.

Based on the readings, it looks like a lot of complexity is introduced when working with large datasets on computers. Whether it be package versions varying or small programming/ file errors, 
making it easier to debug or replicate existing research can save significant ammounts of time. From my own understanding, a large part of scientific development relies on building off the 
work of your predecessors, and doing more to ensure that transfer of work is as replicable as possible streamlines the effort. The book mentions common errors being simple yet prevelent, it
